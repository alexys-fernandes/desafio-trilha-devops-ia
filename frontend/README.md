## 🎯 Sobre o Projeto

**HabitApp** é uma aplicação web moderna que permite aos usuários criar, rastrear e monitorar seus hábitos diários com facilidade. Com uma interface intuitiva e responsiva, você pode acompanhar seu progresso em tempo real e manter-se motivado para alcançar seus objetivos pessoais.

O projeto foi desenvolvido com foco em:
- ✨ Experiência do usuário intuitiva
- 🎨 Design responsivo e moderno
- ⚡ Performance otimizada

## 📋 Pré-requisitos

Antes de começar, certifique-se de ter instalado em sua máquina:

### Obrigatório
- **Node.js** (v18.x ou superior) - [Download](https://nodejs.org/)
- **npm** (v11.x ou superior) - Geralmente vem com Node.js

### Recomendado
- **Angular CLI** v21.2.8 (será instalado como dev dependency)
- **Git** - Para versionamento
- **Editor de Código** - VS Code com extensões Angular recomendadas

### Verificar Instalação

```bash
# Verificar Node.js
node --version
# Esperado: v18.x.x ou superior

# Verificar npm
npm --version
# Esperado: v11.x.x ou superior
