# Decisões de arquitetura e aprendizado

Escolhemos utilizar Angular no frontend e .NET no backend porque essas tecnologias já eram mais familiares para parte da equipe, o que reduziu a curva de aprendizado e acelerou o desenvolvimento do projeto. O Angular foi escolhido principalmente pela facilidade de construir interfaces modernas e responsivas com TypeScript, além de oferecer uma estrutura organizada para criar telas, componentes e fluxos de navegação de forma consistente. Já o .NET foi escolhido por permitir a criação de APIs de maneira robusta e produtiva, especialmente com C#, uma linguagem que já possui semelhanças com Java e que trouxe conforto para quem já tinha experiência com linguagens orientadas a objetos. A combinação entre esses dois ecossistemas também facilitou a integração entre interface e backend, mantendo uma arquitetura mais clara e organizada para o desenvolvimento do HabitApp.

Durante o projeto, aprendemos bastante sobre a integração de inteligência artificial em uma aplicação real, especialmente no contexto de criar um coach de hábitos que respondesse de forma útil e alinhada ao propósito do sistema. Também percebemos a importância de definir bem o escopo e o contexto da IA para evitar respostas fora do tema e manter a experiência do usuário mais consistente. Outro ponto importante foi o processo de deploy, tanto do frontend quanto do backend, e a necessidade de conectar essas duas partes para que o projeto funcionasse de forma integrada em ambientes reais. Por fim, tivemos contato com workflows no GitHub Actions, entendendo como automatizar testes, validações e processos de CI/CD, o que tornou o projeto mais profissional, organizado e preparado para evoluir no futuro.
